# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within the LifeLink platform, please notify the maintainers privately rather than opening a public issue.

- Contact: security@lifelink-project.org or harshadrawat157@gmail.com
- Expected Response Time: Within 48 hours
- Please include reproduction steps, environment details, and proof-of-concept payloads.
